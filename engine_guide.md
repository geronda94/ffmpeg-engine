## 🧠 Ментальная модель

Движок работает по принципу **функционального конвейера**:
1. **Resources**: Глобальный склад сырья.
2. **Pipeline**: Фабрика, где из сырья создаются "потоки" (стеки фильтров).
3. **Compose**: Сборочный цех, где потоки накладываются друг на друга во времени и пространстве.

**Изоляция времени**: Внутри каждого `pipeline step` время `t` всегда начинается с **0**, даже если сам фрагмент вырезан из середины 10-минутного видео.

## 1. Resources (Источники)

Секция `resources` — это массив объектов. Каждый ресурс обязан иметь уникальный `id`.

### Типы ресурсов:
-   **`image` / `video`**:
    -   `source`: Локальный путь (`local_assets/file.mp4`) или URL (`https://...`).
    -   **YouTube**: Если передать ссылку на YouTube, движок автоматически скачает видео в лучшем качестве (до 1080p) через `yt-dlp`.
-   **`audio`**: Звуковые файлы. Также поддерживают URL.
-   **`lavfi`**: Встроенные генераторы FFmpeg (Virtual Sources).
    -   `source`: Строка инициализации фильтра (например, `color=c=black:s=1920x1080:d=10`).

> [!TIP]
> Все внешние ресурсы кэшируются в папку `temp_session/`. Повторный запуск того же конфига не будет скачивать файлы заново.

## 2. Pipeline & Actions (Обработка)

Каждый шаг пайплайна (`pipeline`) создает именованный видеопоток.

```json
{
  "id": "intro_text",
  "input": "black_bg",
  "trim": { "start": 0, "end": 5 },
  "actions": [ ... ]
}
```

### Справочник Actions:

#### 📐 Геометрия и масштаб
- **`scale`**: Жесткое изменение размера.
  - `w`, `h`: Ширина и высота.
- **`scale_contain`**: Вписать в рамку с черными полосами (letterboxing).
- **`scale_and_crop`**: Заполнить рамку полностью, обрезав края. Идеально для фоновых видео.
- **`setsar`**: Сброс Aspect Ratio в 1:1 (решает проблемы с "растянутыми" пикселями).

#### 🖊 Текст и титры (`drawtext`)
- `text`: Текст сообщения.
- `fontsize`: Размер шрифта (по умолчанию 60).
- `fontcolor`: Цвет (имена вроде `white` или HEX `#FF0000`).
- `fontfile`: Путь или **URL** к `.ttf`. Движок скачает шрифт автоматически.
- `x`, `y`: Позиция (поддерживает выражения, см. ниже).
- `box`: `true/false` — включить подложку (плашку).
- `boxcolor`: Цвет плашки (поддерживает прозрачность: `black@0.6`).
- `boxborderw`: Отступы от текста (padding).

#### 🎥 Анимация камеры (`zoom`)
- `zoom`: Конечный коэффициент увеличения (например, `1.2`).
- `smooth`: `true` (по умолчанию) — включает **SuperSampling 4K**. Картинка увеличивается в 4 раза перед зумом, что убирает "дрожание" пикселей на медленных наездах.
- `expr`: Кастомная формула зума. По умолчанию: `min(1+on*(zoom-1)/(fps*10), zoom)`.

#### 🌓 Прозрачность и переходы
- **`fade_in` / `fade_out`**:
  - `duration`: Длительность эффекта.
  - `start_time`: Когда начать (относительно начала слоя).
  - `alpha`: `true` — уводить в прозрачность (для наложения слоев), `false` — уводить в цвет.
  - `color`: Цвет затухания (если `alpha: false`).

#### 🛠 Продвинутые действия
- **`blur`**: `sigma`: радиус размытия.
- **`custom`**: `filter`: Любая строка фильтра FFmpeg (например, `hue=s=0` для ЧБ).

## 3. Математические выражения (Expressions)

Во многих параметрах (`x`, `y`, `expr`, `filter`) можно использовать математику FFmpeg.

### Доступные переменные:
| Переменная | Описание |
| :--- | :--- |
| `w`, `h` | Ширина и высота холста (проекта) |
| `iw`, `ih` | Ширина и высота текущего входного медиа |
| `t` | Время в секундах (внутри слоя всегда от 0) |
| `on` | Номер текущего кадра (начиная с 0) |
| `text_w`, `text_h` | Ширина и высота текста (только в `drawtext`) |

### Полезные формулы:
- **Центрирование**: `x: "(w-text_w)/2", y: "(h-text_h)/2"`
- **Нижняя треть**: `y: "h-h/3"`
- **Дрожание (Shake)**: `x: "(w-iw)/2 + 10*sin(t*20)"`
- **Бегущая строка**: `x: "w - t*200"`

## 4. Compose (Композиция слоев)

Здесь определяется "пирог" видео.

- `base`: Слой-фундамент (обычно на всю длину видео). Его размер определяет разрешение проекта.
- `layers`: Массив наложений.
  - `source`: ID из пайплайна или напрямую из ресурсов.
  - `pos`: `{ "x": "...", "y": "..." }` — где именно разместить слой на холсте.

> [!IMPORTANT]
> **Layer Isolation**: Движок автоматически вычисляет `enable='between(t, start, end)'` для каждого слоя на основе его `trim`. Это значит, что если слой длится с 10-й по 15-ю секунду, он будет занимать память и ресурсы CPU *только* в этом интервале.

---

## 5. Presets (Шаблоны)

Позволяют вынести повторяющиеся цепочки `actions` в отдельный блок.

```json
"presets": {
  "my_style": [
    { "type": "scale_and_crop", "w": 1080, "h": 1920 },
    { "type": "blur", "sigma": 10 }
  ]
}
```
В `pipeline` достаточно указать `"preset": "my_style"`. Действия из пресета выполняются **перед** действиями, указанными в самом шаге.

---

## 6. Audio (Звук)

```json
"audio": {
  "source": "music_id",
  "volume": 0.5,
  "fade_in": 2.0,
  "fade_out": 3.0
}
```
Движок автоматически рассчитывает время начала `fade_out` на основе финальной длительности видео, указанной в `output.duration`.

## 🚀 Примеры

### Пример 1: Текст на размытом фоне
1. Создаем `lavfi` ресурс (черный экран).
2. Создаем `image` ресурс (фон).
3. В `pipeline` для фона применяем `scale_and_crop` и `blur`.
4. Создаем слой с текстом и `fade_in`.
5. Накладываем их в `compose`.

### Пример 2: Видео из YouTube с наездом камеры
1. Ресурс: `source: "https://www.youtube.com/watch?v=..."`.
2. Пайплайн: `trim: { "start": 10, "end": 20 }`, `actions: [ { "type": "zoom", "zoom": 1.5 } ]`.
3. С рендером `smooth: true` это будет выглядеть как профессиональный монтаж без потери четкости.
