# 🎬 Полное руководство по JSON-конфигурации (v2.0)

Это исчерпывающее руководство по созданию видео с помощью FFmpeg Video Assembly Engine. Движок работает по принципу **Data-Driven**: вы описываете, *что* хотите получить в JSON-формате, а скрипт автоматически скачивает медиа, строит сложнейшие графы фильтров FFmpeg и рендерит итоговое видео.

---

## 🏗 Ментальная модель движка

Чтобы писать конфиги, нужно понимать, как мыслит движок:
1. **Ресурсы (Resources)**: Движок собирает весь исходный материал (картинки, видео, звуки, генераторы из интернета или с диска).
2. **Пайплайн (Pipeline)**: Вы берете ресурс и создаете из него независимый **поток (слой)**. Вы можете взять одну картинку и сделать из нее два потока (например, размытый фон и четкий передний план).
3. **Экшены (Actions)**: К каждому потоку последовательно применяются эффекты (зум, текст, фейды). Время внутри потока изолировано (всегда начинается с 0).
4. **Композиция (Compose)**: Все готовые потоки накладываются (overlay) друг на друга как слои в Photoshop, начиная с базового (base).

## 📄 Структура JSON-файла

Ваш конфиг должен содержать 6 корневых блоков:

```json
{
  "version": "2.0",
  "output": { ... },
  "presets": { ... },
  "resources": [ ... ],
  "pipeline": [ ... ],
  "compose": { ... },
  "audio": { ... }
}
```

---

### 1. `output` (Настройки рендера)
Определяет, куда и в каком качестве сохранится видео.
- `path`: Путь сохранения (например, `"output/demo.mp4"`).
- `fps`: Частота кадров (например, `30`). **Важно:** Все картинки будут интерполированы именно в этот FPS, чтобы математические формулы анимации работали идеально.
- `duration`: Длительность видео в секундах.
- `codec`, `preset`, `crf`: Настройки сжатия `libx264`.

---

### 2. `resources` (Источники медиа)
Здесь вы объявляете все файлы, которые будут участвовать в ролике.
Каждому ресурсу дается уникальный `id`.

Поддерживаемые `type`:
- `"image"` / `"video"`: Обычные медиафайлы. `source` может быть локальным путем (`local_assets/img.jpg`) или **прямым URL** (`https://...`). Движок сам скачает файлы из сети в кэш перед рендером!
- `"audio"`: Звуковые файлы (локальные или URL).
- `"lavfi"`: Внутренние синтезаторы FFmpeg. Очень удобно для создания пустышек или генеративного контента:
  - `"color=c=black:s=540x960:d=12"` — черный холст 540x960 на 12 секунд.
  - `"sine=frequency=440:duration=12"` — тестовый писк.

---

### 3. `presets` (Шаблоны)
Если вы применяете одни и те же эффекты к разным слоям, вынесите их в пресеты.
```json
"presets": {
  "bg_style": [
    { "type": "scale_and_crop", "w": 540, "h": 960 },
    { "type": "blur", "sigma": 15 }
  ]
}
```
В пайплайне вы сможете просто указать `"preset": "bg_style"`.

---

### 4. `pipeline` (Конвейер слоев)
Это сердце конфига. Здесь вы берете ресурсы и превращаете их в готовые к наложению слои.
- `id`: Уникальное имя этого слоя (например, `"bg1"`).
- `input`: Ссылка на `id` из секции `resources`.
- `preset`: (Опционально) Имя шаблона.
- `trim`: (Опционально) Вырезает кусок из исходника. `"start": 3.5, "end": 8.5`.
- `actions`: Список эффектов.

**Как работает время в пайплайне:** Если вы сделали `trim` с 3.5 по 8.5 секунды, то для всех `actions` внутри этого слоя время обнуляется. Секунда `0` для экшена — это секунда `3.5` оригинального файла!

---

### 5. Каталог `actions` (Доступные эффекты)

#### Геометрия
- `{ "type": "scale", "w": 540, "h": 960 }` — Жесткое растяжение.
- `{ "type": "scale_contain", "w": 540, "h": 960 }` — Вписать картинку с сохранением пропорций (останутся черные полосы).
- `{ "type": "scale_and_crop", "w": 540, "h": 960 }` — Заполнить экран, обрезав лишнее (отлично подходит для фона).

#### Анимация и переходы
- `{ "type": "blur", "sigma": 15 }` — Размытие слоя.
- `{ "type": "fade_in", "duration": 1.0, "start_time": 0, "alpha": true }` — Плавное появление.
  - Если `"alpha": true`, слой плавно проступает поверх нижних слоев (идеальный кроссфейд).
  - Если `"alpha": false`, слой появляется из цвета (по умолчанию из черного `"color": "black"`).
- `{ "type": "fade_out", ... }` — Плавное затухание (исчезновение).

#### Анимация камеры (Zoom)
Движок умеет делать плавные наезды камеры без дрожания пикселей (Ken Burns effect).
- `"zoom": 1.15` — До какого масштаба приблизить.
- `"smooth": true` — **Магия движка**. Движок сделает 4K (4x) supersampling слоя с `bicubic` интерполяцией, проведет субпиксельный зум и сожмет обратно. Никакой дрожи на медленных наездах!
- `"expr": "..."` — Продвинутые математические функции зума на базе переменной `on` (кадр).

#### Текст и плашки (`drawtext`)
- `"text"`: Текст для вывода.
- `"fontsize"`, `"fontcolor"`: Размер и цвет (можно HEX: `"#00FF66"` или имена: `"gold"`).
- `"fontfile"`: **URL или локальный путь к `.ttf` шрифту**. Движок сам скачает шрифт с GitHub или Google Fonts! Если не указать, используется дефолтный.
- `"x"` и `"y"`: Математические выражения для позиции. `"(w-text_w)/2"` — центр.
- **Плашки для читаемости**:
  - `"box": true` — Включает плашку под текстом.
  - `"boxcolor": "black@0.6"` — Цвет плашки (0.6 — это 60% непрозрачности).
  - `"boxborderw": 30` — Отступы (padding) плашки от текста в пикселях.

---

### 6. `compose` (Сборка слоев)
В этом блоке мы определяем порядок бутерброда.
- `"base"`: Самый нижний слой (id из `pipeline`). Обычно это `lavfi` генератор черного экрана на всю длину видео.
- `"layers"`: Массив слоев снизу вверх. Слой, указанный последним, будет поверх всех.

**💡 Умная оптимизация памяти (Layer Isolation):**
Движок анализирует `trim` каждого слоя. Когда слой заканчивается, движок автоматически применяет FFmpeg параметр `enable`, который полностью выгружает этот слой из памяти. Вам не нужно об этом думать — даже проект из 100 слоев не сожрет вашу ОЗУ!

---

### 7. `audio` (Звуковая дорожка)
Если вашему видео нужен звук, добавьте этот блок.
```json
"audio": { 
  "source": "music",   // id ресурса (из секции resources)
  "volume": 0.8,       // Громкость (1.0 = 100%)
  "fade_in": 1.0,      // Плавное нарастание в начале
  "fade_out": 2.0      // Движок сам вычислит, когда начать fade_out!
}
```

---

## 🛠 Пример идеального workflow
1. Опишите черный холст в `resources`.
2. Добавьте ссылки на `image` ресурсы с Unsplash.
3. В `presets` опишите стиль фона (растянуть + заблюрить).
4. В `pipeline` пропишите тайминги. Например, `img1` с 0 до 5 секунд, `img2` с 5 до 10. Наложите на них `fade_in` и `fade_out` с `alpha: true` для кроссфейдов.
5. Настройте `compose` и запустите `python main.py --task tasks/ваш_конфиг.json`.
