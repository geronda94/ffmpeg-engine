# 🎨 Справочник эффектов и спецификация параметров
> **СТРОГОЕ ПРАВИЛО:** При сборке пайплайна соблюдайте порядок: [Геометрия] -> [Анимация] -> [Прозрачность].

---

## 📐 Геометрия (Всегда ПЕРВЫМИ в списке actions)

### `scale_and_crop`
Заполнение области с обрезкой центра (Fill).
- `w`, `h`: Целевое разрешение (обычно 1080x1920).

### `zoom`
Эффект Ken Burns.
- `zoom`: Конечный масштаб (например, `1.2`).
- `smooth`: `true` (обязательно для плавной анимации).
- **ВНИМАНИЕ**: Всегда ставьте `zoom` ПЕРЕД любыми эффектами прозрачности (`fade_in`, `dissolve`).

### `region_blur`
Локальное размытие части кадра (эффект матового стекла под плашкой).

**Параметры:**
- `w`, `h`: Размеры области (по умолчанию 900x250).
- `x`, `y`: Координаты (по умолчанию центр). Поддерживают константы `W, H, w, h`.
- `sigma`: Сила размытия (по умолчанию 40).
- `radius`: Ширина растушевки краев в пикселях (по умолчанию 50). Чем выше, тем мягче переход к резкому фону.
- `start`, `end`: Временные рамки работы эффекта внутри слоя.
- `enabled`: Включение/выключение (true/false).

**Пример:**
```json
{ 
  "type": "region_blur", 
  "w": 900, "h": 250, 
  "x": "(W-w)/2", "y": "800", 
  "sigma": 40, "radius": 60 
}
```

## 🎬 Прозрачность и Появление (Всегда ПОСЛЕДНИМИ в списке actions)

### `fade_in`
Плавное появление слоя из прозрачности.
- `duration`: Длительность (например, `1.5`).
- `alpha`: `true` (обязательно для наложений).

### `fade_out`
Плавное исчезновение слоя.
- `duration`: Длительность затухания.
- `alpha`: `true`.
- **Логика**: Движок автоматически вычисляет момент начала затухания так, чтобы слой стал полностью прозрачным ровно в конце своего `trim`.

### `dissolve`
Автоматический кроссфейд (упрощенный `fade_in` с альфа-каналом).
- `duration`: Длительность перехода.

## 💎 Элементы интерфейса (UI)

### `plate` (УСТАРЕЛО / DRAFT)
Используется только для быстрой отладки или простых прямоугольников. 
- `w`, `h`: Размеры.
- `boxcolor`: Цвет (например, `black@0.5`).
- **ЗАПРЕТ**: Не используйте параметры `radius` и `blur` — они нестабильны. Для скругленных углов используйте PNG.

### **Best Practice: PNG UI Assets**
Для качественных плашек под текст используйте готовые ассеты:
1. Объявите ресурс: `{"id": "ui_bg", "source": "local_assets/ui/plate_dark.png", "type": "image"}`.
2. В пайплайне задайте длительность: `{"id": "ui_layer", "input": "ui_bg", "trim": {"start": 2, "end": 10}}`.
3. В `compose` разместите под текстом.

## 🖊 Текст

### `drawtext`
Вывод титров.
- `text`: Содержимое.
- `fontsize`: Размер.
- `fontcolor`: Цвет (рекомендуется `white`).
- `x`, `y`: Позиция. Центровка: `(w-text_w)/2`.

---

## 🔊 Звук

### `volume`
- `1.0` — база.
- `0` — мут (используется для видео-слоев в пайплайне, если звук из видео не нужен).

### `fade_in` / `fade_out`
- `duration`: Длительность затухания.
- **Логика**: Для `fade_out` движок сам находит точку старта в конце видео.
