# Архитектура "Контент-Завод v9.6" 🏭🎬

Система представляет собой высокоуровневый движок автоматизированного видеопроизводства, способный работать через Telegram, API или локальную консоль.

## 🏗 Ключевая концепция: Single Source of Truth
Все данные проекта теперь хранятся не в памяти, а в изолированной файловой структуре:
`projects/{user_id}/{project_id}/project.json`

Это позволяет:
- Восстанавливать работу после сбоев.
- Использовать одни и те же ассеты для рендера на разных языках.
- Управлять проектами через внешние API (FastAPI).

## 🧩 Компоненты системы

### 1. Ядро управления (`core/`)
- `project_manager.py`: CRUD операции над проектами, управление ассетами, логика объединения/разделения сцен.

### 2. Видео-движок (`ai/`)
- `montage_agent.py`: ООП-движок. Содержит `VerticalMontageEngine` и `WideMontageEngine`. Реализует алгоритмы "Smart Blur" и защиту от артефактов зума.
- `timing_agent.py`: Точная синхронизация на базе Whisper.

### 3. Пайплайн (`bot/pipeline_manager.py`)
- Оркестратор, связывающий ИИ-агентов с менеджером проектов. Гарантирует, что все промежуточные результаты (аудио, ассеты) будут сохранены в папку проекта.

## 📐 Форматы и Стили
Система строго разделяет пресеты по геометрии:
- **9:16 (Vertical)**: Оптимизировано под Shorts/TikTok.
- **16:9 (Wide)**: Оптимизировано под YouTube.

## 🛠 Запуск и Тестирование
- **Бот**: `python bot/bot_app.py`
- **Локальный рендер**: `python tools/local_render.py {project_id}`
- **Временные файлы**: Всегда в `temp/`, очищаются автоматически.
