# AI Montage Engine Architecture v10.0

## 1. Обзор системы
Система представляет собой модульный конвейер для автоматического создания видео на основе ИИ. Проект переведен на "плоскую" структуру хранения, где каждый проект — это самодостаточная директория.

## 2. Структура данных (Flat Hierarchy)
```text
projects/
└── {project_id}/
    ├── project.json          # Единый источник истины (Сценарий, Сцены, Тайминги)
    ├── audio/
    │   └── voice_{lang}.wav  # Сгенерированная озвучка
    ├── assets/
    │   └── scene_{idx}.{ext} # Исходные материалы (фото/видео)
    └── {project_id}_final.mp4 # Готовый результат
```

## 3. Ключевые компоненты

### 🧠 Storyboard Agent (bot/handlers/scripting.py)
*   **Функция**: Интерактивное планирование видеоряда.
*   **Особенности**: Поддерживает диалоговое редактирование (объединение, разделение сцен) через ИИ.
*   **Контракт**: Гарантирует сохранение дословного текста сценария в `text_segment` для точного тайминга.

### 🎙 Timing Agent (ai/timing_agent.py)
*   **Функция**: Синхронизация аудио и видео.
*   **Механика**: Использует OpenAI Whisper для транскрибации и поиска вхождений ключевых слов из `text_segment`.
*   **Результат**: Проставляет точные поля `start` и `end` в `project.json`.

### 📂 Project Manager (core/project_manager.py)
*   **Функция**: CRUD операции с проектами и ассетами.
*   **Особенности**: Автоматическая инициализация структуры при первом обращении.

### 🎬 Montage Agent (ai/montage_agent.py)
*   **Функция**: Сборка финального видео через FFmpeg.
*   **Логика**: Опирается на пресеты (`config/montage_presets.json`) и тайминги из `project.json`.

## 4. Жизненный цикл проекта (Pipeline)
1.  **Scripting**: Генерация темы -> Правка текста -> Утверждение.
2.  **Storyboarding**: Агент Сцен предлагает план -> Интерактивная правка -> Утверждение.
3.  **Voiceover**: Генерация TTS -> Согласование озвучки.
4.  **Assets**: Сбор материалов (ИИ-генерация, ручная загрузка или ссылки).
5.  **Synchronization**: Whisper анализирует голос и расставляет тайминги сцен в JSON.
6.  **Production**: Финальный рендер на основе пресетов и таймингов.

## 5. Планы по развитию
*   **Overlay Agent**: Наложение текстовых плашек и графики на основе таймингов сцен.
*   **Music Agent**: Подбор фоновой музыки под настроение и темп речи.
*   **Translation Module**: Полный цикл перевода (скрипт + сегменты + озвучка) с сохранением ID сцен.
