# AI Montage Engine v11.0: Architecture

Система представляет собой интеллектуальный конвейер для автоматизированного создания видеоконтента (Shorts/Reels/TikTok) на основе ИИ.

## 1. Концепция Трех Агентов
Система управляется тремя специализированными ИИ-модулями:

1.  **Storyboard Agent (DeepSeek-V3)**: 
    *   Генерирует сценарий, разбивает его на сцены.
    *   Формирует визуальные промпты для генерации изображений/видео.
    *   Гарантирует логическую связность текста.

2.  **Timing Agent (Whisper)**:
    *   Анализирует сгенерированную озвучку.
    *   Выполняет пословную синхронизацию (Word-level alignment).
    *   Проставляет **абсолютные** метки начала (`start`) и конца (`end`) каждой сцены в `project.json`.

3.  **Metadata Agent (DeepSeek-V3)**:
    *   Анализирует готовый сценарий.
    *   Генерирует хайповый заголовок, SEO-описание и хештеги на языке проекта.
    *   Создает `slug` для человекочитаемого именования файлов.

## 2. Монтажный Движок: Absolute Timeline
Ключевое отличие версии 11.0 — переход от последовательной склейки к **абсолютному позиционированию**.

*   **Никакого смещения**: Каждый клип ставится точно на ту секунду, которую определил Whisper.
*   **Gap Filling**: Если в речи диктора есть пауза, предыдущий кадр автоматически растягивается до начала следующего, исключая «черные экраны».
*   **Seamless Transitions**: Переходы (crossfade) реализуются через наложение слоев (overlap). Предыдущий кадр остается активным под новым в течение времени перехода.

## 3. Аудио-конвейер: AI-Optimized TTS
Перед озвучкой текст проходит через этап оптимизации:
*   Разворачивание сокращений и чисел (10% -> десять процентов).
*   Расстановка пауз через спецсимволы (`...` для вдоха, `—` для акцента).
*   Адаптация ритма под конкретный язык для минимизации ошибок в ударениях.

## 4. Структура Проекта
Все проекты теперь имеют плоскую структуру в папке `projects/{project_id}/`:
*   `project.json` — «мозг» проекта, содержащий все тайминги и метаданные.
*   `assets/` — сгенерированные или загруженные визуальные материалы.
*   `audio/` — озвучка и фоновая музыка.
*   `{slug}.mp4` — финальный результат с SEO-именем.

## 5. Инструменты (Tools)
Для быстрой отладки выделена папка `tools/`:
*   `tts_test.py` — Интерактивный подбор голоса и проверка пауз.
*   `render_only.py` — Перерендеринг проекта без участия бота.
*   `montage_tool.py` — Тестирование визуальных эффектов и пресетов.
