# Система Пресетов Визуального Монтажа 🎨🎬

В системе "Контент-Завод" пресеты управляют тем, как видео будет "чувствоваться" зрителем (плавность, динамика, эффекты).

## 1. Структура Конфигурации (`config/montage_presets.json`)

Пресеты разделены на две основные ветки по форматам. Это позволяет избежать конфликтов геометрии.

```json
{
  "vertical": [...], // Пресеты для 9:16 (Shorts/TikTok)
  "wide": [...]     // Пресеты для 16:9 (YouTube)
}
```

### Параметры пресета:
- `id`: Уникальный идентификатор.
- `name`: Название, которое видит пользователь в боте.
- `effects`: Список строковых идентификаторов эффектов (например, `soft_zoom`, `quick_zoom`).
- `transition`: Объект настроек перехода.
  - `type`: Тип перехода (на данный момент поддерживается `crossfade`).
  - `duration`: Длительность перехода в секундах.

## 2. Архитектура управления (Python)

### Класс-оркестратор: `BaseMontageEngine` (`ai/montage_agent.py`)
Этот класс является "переводчиком" между JSON-конфигом и библиотекой MoviePy.

- **Метод `apply_preset_effects(clip, effects_list)`**: 
  - Проходит по списку `effects` из пресета.
  - Сопоставляет их с конкретными функциями MoviePy (`vfx.Resize`).
  - **Критическая логика**: Здесь реализован коэффициент `1.05` для зума, чтобы предотвратить появление черных рамок.

- **Метод `render(...)`**:
  - Извлекает `transition` из пресета.
  - Применяет `vfx.CrossFadeIn` к каждой сцене, кроме первой.
  - Управляет параметром `padding` в функции `concatenate_videoclips` (отрицательный паддинг создает нахлест клипов для перехода).

### Специализированные классы: `VerticalMontageEngine` и `WideMontageEngine`
Они получают уже отфильтрованный пресет и используют его при обработке переднего плана (`fg`) в методе `process_scene_asset`.

## 3. Жизненный цикл пресета в системе

1. **Выбор**: Бот предлагает пресеты на основе формата (vertical/wide).
2. **Передача**: `pipeline_manager` передает объект пресета в `run_montage`.
3. **Синхронизация**: Движок использует тайминги `start` и `end` из каждой сцены для точного наложения эффектов.
4. **Индексация**: Ассеты привязываются к сценам по их порядковому номеру (индексу).

## 4. Перспективы: Динамические оверлеи
Благодаря фиксации таймингов в `project.json`, пресеты смогут включать в себя инструкции по отрисовке титров и графики, привязанных к конкретным сценам.

## 4. Как добавлять новые эффекты в будущем
Чтобы добавить новый эффект (например, "Черно-белое видео" или "Глитч"):
1. Добавить ID эффекта в `config/montage_presets.json`.
2. В `ai/montage_agent.py` в методе `apply_preset_effects` добавить обработку этого ID:
   ```python
   if effect == "grayscale":
       new_effects.append(vfx.BlackAndWhite())
   ```
