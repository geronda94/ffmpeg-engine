# 🛠 Система Пресетов (Customization Guide)

Проект **AI Video Factory** спроектирован так, чтобы вы могли менять поведение бота, стили видео и голоса, не меняя ни строчки программного кода. Все настройки хранятся в папке `config/` в формате JSON.

---

## 1. Контекст Канала (`channel_context.json`)
Это "личность" вашего проекта. СЕО-агент и сценарист используют этот файл, чтобы подстроиться под вашу нишу.

*   `channel_topic`: О чем ваш канал (например, "Интересные факты о космосе").
*   `tone_of_voice`: Как бот общается с аудиторией (Engaging, Professional, Humorous).
*   `target_platform`: Куда выкладываем (YouTube Shorts, TikTok).
*   `avoid_topics`: Темы-табу, которые ИИ никогда не затронет.

---

## 2. Динамические Сцены (`dynamic_scenes.json`)
Библиотека графических шаблонов. Здесь вы описываете, какие элементы (фото, видео или текст) бот должен запросить у пользователя для сборки сцены.

**Пример структуры:**
```json
{
  "id": "price_tag",
  "name": "💎 Акцент на цену",
  "elements": [
    {"id": "bg", "name": "Фон", "type": "media"},
    {"id": "title", "name": "Товар", "type": "text"},
    {"id": "price", "name": "Цена", "type": "text"}
  ]
}
```
*Если вы добавите сюда новый блок, он автоматически появится в меню бота.*

---

## 3. Аудио и Голоса (`audio_presets.json`)
Здесь настраиваются движки озвучки (TTS) и доступные голоса.

*   `tts_engines`: Список провайдеров (Edge-TTS, ElevenLabs).
*   `presets`: Конкретные голоса с их ID и характеристиками (Gender, Style).
*   `default_music`: Фоновые треки, которые предлагаются для подложки.

---

## 4. Стили Сценариев (`script_presets.json`)
Настройки для LLM (DeepSeek), которые определяют структуру и длину сценария.

*   `max_segments`: Ограничение по количеству сцен.
*   `segment_duration_target`: Желаемая длительность одной сцены (обычно 3-7 сек для Shorts).
*   `system_prompts`: "Инструкции", которые заставляют ИИ писать именно в нужном вам стиле (например, "Пиши как детектив" или "Пиши максимально просто").

---

## 5. Визуальные Стили (`visual_presets.json`)
Параметры для генератора изображений и монтажного движка.

*   `aspect_ratio`: 9:16 (вертикально) или 16:9 (горизонтально).
*   `negative_prompt`: Что ИИ НЕ должен рисовать (артефакты, текст, искажения).
*   `transitions`: Типы переходов между сценами по умолчанию.

---

### Как применить изменения?
1. Отредактируйте нужный файл в папке `config/`.
2. Перезапустите бота (или просто начните новый проект).
3. Бот автоматически подхватит новые настройки и отобразит их в меню.
