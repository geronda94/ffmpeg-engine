# FFmpeg Video Assembly Engine v2.0

Движок для автоматической сборки видеороликов (Reels, Shorts) на основе JSON-конфигурации.

## Ключевые возможности
- **Полный Data-Driven контроль**: Вся логика эффектов (кроссфейды с альфа-каналом, математические формулы анимации) описывается строго в JSON. Python-код больше не содержит "жесткой" логики.
- **Автоматическая загрузка**: Поддержка прямых ссылок (HTTP/HTTPS). Ресурсы скачиваются во временную папку и удаляются после сборки.
- **Система пресетов**: Группировка наборов эффектов для переиспользования в JSON.
- **Продвинутый Zoom**: Поддержка произвольных математических выражений (Ken Burns, punchy zoom) через параметр `expr` со сглаживанием `smooth: true`.
- **Слоистая композиция**: Наложение неограниченного количества слоев с гибким позиционированием и честной прозрачностью.
- **Авто-аудио**: Наложение звука с автоматическим fade-in/fade-out под длительность видео.

## Быстрый старт
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сборки
python main.py --task tasks/religious_reel.json
```

## Структура проекта
- `main.py`: Оркестратор сборки и управление сессиями.
- `engine/`:
  - `resolver.py`: Загрузка и кэширование ресурсов.
  - `filter_builder.py`: Генерация сложнейших цепочек фильтров FFmpeg.
  - `schema.py`: Валидация JSON через Pydantic.
  - `runner.py`: Исполнение команд FFmpeg с выводом прогресса.
- `tasks/`: Папка для ваших JSON-конфигов.
- `output/`: Результаты сборки.

## Как это работает
Движок парсит JSON, скачивает ресурсы, строит одну гигантскую строку `-filter_complex` (включая масштабирование, размытие, анимацию и наложение) и запускает FFmpeg. Каждый слой обрабатывается изолированно в своем временном пространстве, что гарантирует точность эффектов.
