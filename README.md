# 🎬 AI Content Factory (v11.0)

Профессиональный ИИ-конвейер для создания вирального видеоконтента.

## ✨ Ключевые возможности
*   🤖 **Триада Агентов**: Storyboard (сценарий), Timing (синхронизация), Metadata (SEO-упаковка).
*   ⏱️ **Perfect Sync**: Пословная синхронизация через Whisper и абсолютный таймлайн монтажа.
*   🎙️ **AI-Optimized TTS**: Интеллектуальная подготовка текста для естественного звучания диктора (Edge-TTS/ElevenLabs).
*   📈 **SEO-Ready**: Автоматическая генерация хайповых заголовков, описаний и хештегов.
*   🎭 **Visual Styles**: Гибкая система пресетов для изменения атмосферы видео в один клик.

## 🚀 Быстрый старт
1.  Установите зависимости: `pip install -r requirements.txt`
2.  Настройте ключи в `.env`: `TELEGRAM_TOKEN`, `DEEPSEEK_API_KEY`, `ELEVENLABS_API_KEY`.
3.  Запустите бота: `python3 bot/bot_app.py`

## 🛠️ Инструменты разработчика
Все инструменты тестирования вынесены в папку `/tools`:
*   `tts_test.py` — интерактивный подбор голоса.
*   `render_only.py` — быстрый рендеринг без бота.
*   `montage_tool.py` — проверка визуальных эффектов.

## 📁 Структура проекта
*   `/ai` — ИИ агенты и движки озвучки.
*   `/bot` — логика Telegram-бота (Aiogram 3).
*   `/core` — менеджер проектов и файловая система.
*   `/projects` — база данных проектов и ассетов.
*   `/config` — настройки стилей и голосов.
