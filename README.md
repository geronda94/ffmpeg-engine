# AI Montage Engine v10.0 🦾📽️🚀

Мощный конвейер для автоматического создания видеороликов с использованием ИИ (DeepSeek, Gemini, Whisper, FFmpeg).

## 🌟 Что нового в v10.0 (Stability & Storyboard Update)

### 🧠 Интерактивный Агент Сцен (Storyboard Agent)
*   **Диалоговое планирование**: Теперь вы можете обсуждать раскадровку с ИИ.
*   **Гибкое редактирование**: Команды вроде "объедини 1 и 2 сцены" или "разбей 5-ю сцену на две" выполняются мгновенно.
*   **Визуальный контекст**: Бот показывает не только текст, но и описание визуала для каждой сцены.

### 🎙 Точная Синхронизация (Whisper Precision)
*   **Keyword Matching**: Переход от примерных таймингов к точной привязке "кадр в слово".
*   **Persistence**: Тайминги сцен (`start`/`end`) теперь навсегда сохраняются в `project.json`, что позволяет делать доп. монтаж позже.

### 📂 Архитектурная Стабильность
*   **Flat Structure**: Упрощенная система хранения проектов `projects/{project_id}/`.
*   **Robustness**: Защита от битых ссылок, ошибок ИИ и лимитов Telegram (авто-дробление сообщений).

## 🚀 Быстрый старт

1.  **Настройка**: Создайте `.env` и добавьте ключи:
    ```bash
    TELEGRAM_TOKEN=...
    DEEPSEEK_API_KEY=...
    GEMINI_API_KEY=...
    ```
2.  **Запуск**:
    ```bash
    python bot/bot_app.py
    ```

## 🛠 Технологический стек
*   **Бот**: Aiogram 3.x (FSM, Роутеры)
*   **ИИ Текст**: DeepSeek-V3 (Сценарии и Агент Сцен)
*   **ИИ Картинки**: Google Gemini (Imagen fallback)
*   **Голос**: Edge-TTS
*   **Синхронизация**: OpenAI Whisper (Local)
*   **Рендеринг**: FFmpeg (через MoviePy-based MontageAgent)

## 📂 Структура проекта
*   `bot/`: Хендлеры и логика Telegram-интерфейса.
*   `ai/`: Мозги системы (генерация, транскрибация, монтаж).
*   `core/`: Менеджер проектов и база данных (JSON).
*   `config/`: Пресеты монтажа, голосов и стилей.
*   `projects/`: Рабочие директории ваших видео.
