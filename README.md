# FFmpeg Video Assembly Engine v3.2 🚀

Мощный инструмент для автоматической генерации видеоконтента (Reels, Shorts, рекламные креативы) на основе JSON-конфигураций. Движок берет на себя всю рутину: от скачивания ресурсов до построения сложнейших графов фильтров FFmpeg.

## 🌟 Ключевые возможности

-   **Modular Action System**: Каждый эффект (зум, блюр, текст) вынесен в отдельный модуль. Легко расширять и поддерживать.
-   **Glassmorphism & UI**: Создание "премиальных" интерфейсов прямо в видео (размытие фона под плашками, скругление углов, свечение).
-   **Multi-Track Audio**: Поддержка неограниченного количества аудиодорожек с индивидуальными задержками (`start`), громкостью и фейдами.
-   **Авто-резолвер ресурсов**:
    -   Прямые ссылки (HTTP/HTTPS).
    -   **YouTube**: Просто вставьте ссылку на видео, и движок сам его скачает.
    -   **Google Fonts**: Автоматическая загрузка шрифтов по URL.
-   **Ken Burns 2.0**: Плавный субпиксельный зум без дрожания за счет 4K-суперсэмплинга.
-   **Memory Isolation**: Рендеринг тяжелых проектов на слабом железе за счет умного управления памятью слоев.

## 🚀 Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск демонстрационного задания (всё скачается само!)
python main.py --task tasks/task.json
```

## 🏗 Архитектура
Движок реализует многослойный монтаж через три этапа:
1. **Resources**: Декларация исходных файлов. Поддерживает статичные изображения, видео и зацикленные анимации (`loop_video`).
2. **Pipeline**: Независимая обработка каждого слоя (обрезка, масштабирование, наложение текста, эффекты появления).
3. **Compose**: Финальная сборка слоев на холсте с использованием точной синхронизации времени.

## 🎙 Утилиты озвучки (TTS)
В папке `tools/` доступен генератор озвучки на базе Google Gemini:
- **`tts_generator.py`**: Позволяет генерировать качественную озвучку из текста с использованием различных голосов (Alnilam, Puck и др.).
  - **Использование**: `python tools/tts_generator.py --input speech.txt --output local_assets/audio/voice.wav`
  - **Настройка**: Требует API-ключ в файле `.env`.

## Структура проекта

-   `engine/actions/`: Библиотека визуальных модулей (геометрия, текст, анимация, плашки).
-   `engine/resolver.py`: Умная загрузка и кэширование (YouTube, Fonts, Web).
-   `engine/filter_builder.py`: Сборка высокоуровневого графа фильтров.
-   `main.py`: Точка входа и управление процессом рендеринга.
