# 🎨 Библиотека эффектов и переходов (v1.0)

Этот справочник содержит подробное описание всех визуальных действий (`actions`), доступных в FFmpeg Video Assembly Engine.

---

## 📐 Геометрия и Масштабирование

### `scale`
Жесткое изменение размера кадра.
- **Параметры**:
  - `w`, `h`: Целевая ширина и высота (например, 1080, 1920).
- **Пример**: `{ "type": "scale", "w": 1080, "h": 1920 }`

### `scale_and_crop`
Заполнение области с обрезкой лишнего (Fill). Идеально для фонов.
- **Параметры**:
  - `w`, `h`: Целевые размеры.
- **Логика**: Масштабирует по меньшей стороне и обрезает центр.

### `scale_contain`
Вписывание в область с сохранением пропорций (Fit). Оставляет черные полосы.
- **Параметры**:
  - `w`, `h`: Целевые размеры.

### `setsar`
Сброс Sample Aspect Ratio в 1:1. Используйте, если видео кажется "сплюснутым".

## 🎬 Анимация и Переходы

### `zoom` (Ken Burns Effect)
Плавный наезд или отъезд камеры.
- **Параметры**:
  - `zoom`: Конечный масштаб (1.0 - 2.0).
  - `smooth`: `true` (по умолчанию). Использует 4K-апскейл для плавной анимации без дрожания пикселей.
  - `expr`: Кастомная математическая формула (например, для циклического зума).

### `zoom_blur` [NEW]
Наезд камеры с эффектом размытия в движении (Motion Blur).
- **Параметры**:
  - `zoom`: Конечный масштаб.
  - `blur`: Сила размытия на пике зума.
- **Эффект**: Создает ощущение динамики и скорости.

### `fade_in` / `fade_out`
Плавное появление или исчезновение.
- **Параметры**:
  - `duration`: Длительность в секундах.
  - `start_time`: Задержка перед началом.
  - `alpha`: `true` для прозрачности (кроссфейд), `false` для фейда в цвет.
  - `color`: Цвет затухания (по умолчанию `black`).

### `dissolve` [NEW]
Классическое "растворение" одного слоя в другом.
- **Параметры**:
  - `duration`: Длительность.
- **Особенности**: Автоматически использует прозрачность (`alpha: true`), что делает его идеальным для переходов между кадрами.

## 💎 Современный UI (Glassmorphism)

### `plate`
Создает "стеклянную" подложку под текст или другие элементы.
- **Параметры**:
  - `w`, `h`, `x`, `y`: Геометрия плашки.
  - `blur`: Интенсивность размытия фона под ней.
  - `radius`: Скругление углов (мягкий дизайн).
  - `boxcolor`: Цвет заливки с прозрачностью (например, `white@0.15`).
  - `border_width`, `border_color`: Параметры рамки.

---

## 🖊 Текст и Титры

### `drawtext`
Вывод текста на экран.
- **Параметры**:
  - `text`: Строка текста.
  - `fontsize`, `fontcolor`: Стиль.
  - `fontfile`: Путь или URL к шрифту.
  - `x`, `y`: Позиция (поддерживает переменные `w`, `h`, `tw`, `th`).
  - `box`, `boxcolor`, `boxborderw`: Базовая квадратная подложка (устарело, используйте `plate` для лучшего вида).

## 🛠 Математика в параметрах

Вы можете использовать переменные FFmpeg в параметрах `x`, `y`, `expr`:
- `w`, `h`: Ширина/высота проекта.
- `iw`, `ih`: Ширина/высота входного файла.
- `t`: Время в секундах.
- `on`: Номер кадра.
- `text_w`, `text_h`: Размеры текста.

**Пример центра**: `"x": "(w-text_w)/2", "y": "(h-text_h)/2"`
