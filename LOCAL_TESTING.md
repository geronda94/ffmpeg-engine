# Локальное тестирование и отладка (v11.0)

Для ускорения разработки и проверки изменений без использования Telegram-бота, используйте инструменты в папке `tools/`.

## 1. Тестирование озвучки (TTS Test)
Позволяет проверить качество произношения, расстановку пауз и работу ИИ-оптимизатора текста.

```bash
python3 tools/tts_test.py {project_id}
```
**Возможности:**
*   Интерактивный выбор голоса (Edge TTS / ElevenLabs).
*   Автоматическая оптимизация текста через DeepSeek.
*   Сохранение аудио в `projects/{id}/audio/test_{voice}.wav`.

## 2. Автономный рендеринг (Render Only)
Запуск финального монтажа видео на основе текущего `project.json`.

```bash
python3 tools/render_only.py {project_id}
```
**Когда использовать:**
*   После ручной правки таймингов в JSON.
*   После замены ассетов в папке `assets/`.
*   При необходимости изменить стиль монтажа (пресет).

## 3. Отладка визуальных эффектов (Montage Tool)
Тестирование конкретных визуальных пресетов на коротких отрезках.

```bash
python3 tools/montage_tool.py {project_id}
```

## 4. Структура проекта для тестов
При ручной отладке убедитесь, что файлы расположены верно:
*   `projects/{id}/project.json` — основной конфиг.
*   `projects/{id}/assets/` — здесь должны быть изображения/видео (scene_0.jpg, scene_1.jpg и т.д.).
*   `projects/{id}/audio/` — здесь должен лежать файл озвучки.

## 5. Быстрая правка таймингов
Если вы видите рассинхрон, вы можете вручную изменить значения `"start"` и `"end"` в `project.json` и сразу запустить `tools/render_only.py`. Система подхватит ваши изменения мгновенно.
