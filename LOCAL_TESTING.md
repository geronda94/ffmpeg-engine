# Руководство по локальному управлению проектами 🛠

Этот документ описывает, как вручную редактировать конфиги проектов и запускать рендер без Telegram.

## 1. Где лежат проекты
Все проекты хранятся в папке:
`projects/{user_id}/{project_id}/`

Внутри каждой папки:
- `project.json`: Главный конфиг.
- `assets/`: Фото и видео для сцен.
- `audio/`: Файлы озвучки.

## 2. Как настроить `project.json` вручную

Вы можете создать или изменить существующий проект, отредактировав JSON:

### Важные поля:
- `video_format`: `"vertical"` или `"wide"`.
- `visual_style`: ID пресета из `config/montage_presets.json` (например, `v_dynamic_shorts` или `w_cinematic`).
- `scenes`: Список объектов. Каждый должен иметь `text_segment`.
- `assets`: Мапа `"номер_сцены": {"path": "путь_к_файлу"}`.
- `current_audio_path`: Полный путь к файлу озвучки.

**Пример минимального конфига для рендера:**
```json
{
  "project_id": "test_1",
  "video_format": "wide",
  "visual_style": "w_cinematic",
  "scenes": [{"text_segment": "Привет мир"}],
  "assets": {"0": {"path": "projects/default/test_1/assets/scene_0.jpg"}},
  "current_audio_path": "projects/default/test_1/audio/voice_Russian.wav"
}
```

## 3. Локальный запуск рендера

Убедитесь, что вы находитесь в корне проекта и активировали `.venv`.

**Команда для запуска:**
```bash
python tools/local_render.py {project_id}
```
*Если вы не указывали user_id в боте, по умолчанию используется `default`.*

**Зачем это нужно:**
1. **Тестирование пресетов**: Измените `visual_style` в JSON и запустите команду — вы увидите, как меняется монтаж на тех же исходниках.
2. **Массовый рендер**: Можно написать Bash-скрипт, который прогонит все папки проектов через рендер.
3. **Отладка**: В консоли вы увидите подробные ошибки MoviePy, если что-то пойдет не так.
